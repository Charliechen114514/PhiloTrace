# 如何阅读本站

## 这是什么

PhiloTrace（哲思留痕）是一个**开放式哲学学习与对话笔记站**。

它不是哲学百科，不是严肃论文库，也不是 AI 内容农场。它更接近：

- 朋友之间的思想讨论；
- 读书时写在页边的批注；
- 一个普通人逐渐理解哲学的路径。

## 内容门类

| 门类 | 是什么 | 适合谁 |
| --- | --- | --- |
| [随笔](/passages/) | 围绕一个问题展开的文章 | 想读点完整东西的人 |
| [对话](/dialogues/) | 脱敏后的讨论整理 | 喜欢看思想被"聊"出来的人 |
| [概念](/concepts/) | 一个概念讲清楚 | 刚遇到陌生术语的人 |
| [笔记](/notes/) | 学习记录 | 想跟着一起学的人 |
| [图谱](/maps/) | 关系图、路线图 | 想看全貌的人 |
| [反思](/reflections/) | 阶段回望 | 想看"理解如何变化"的人 |

## 怎么读

1. **不知道从哪开始**：先看 [图谱里的学习路线](/maps/)。
2. **遇到不懂的词**：去 [概念](/concepts/) 里查。
3. **想看完整的思考**：读 [随笔](/passages/)。
4. **想看思考的过程**：读 [对话](/dialogues/)。

## 可以纠错

所有页面右上角有"在 GitHub 上编辑此页"。发现理解错误、事实错误、表达不清，欢迎直接提 Issue 或 PR。这里的内容**可以被指出错误、可以持续修订**。
